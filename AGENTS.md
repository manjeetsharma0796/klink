# AGENTS.md

AI contributors must read this before editing, creating, or committing any doc on this project.

## Workflow per edit

1. **Read [`DOCS_INDEX.md`](DOCS_INDEX.md)** first — see what exists. Edit an existing doc over creating a new one.
2. **Make the change.**
3. **Update `last_updated`** in the touched doc's frontmatter.
4. **Update `DOCS_INDEX.md`** — add, edit, or remove the entry so it matches reality.

## Doc conventions

- **Filenames**: `kebab-case.md`.
  - Specs → `docs/specs/YYYY-MM-DD-<topic>-design.md`
  - Architecture → `docs/architecture/<system>.md`
  - Runbooks → `docs/runbooks/<task>.md`
  - Memos → `docs/memos/YYYY-MM-DD-<topic>.md`
- **Frontmatter required** at the top of every doc:

  ```yaml
  ---
  title: <one-line title>
  purpose: <one-line; what question this doc answers>
  last_updated: YYYY-MM-DD
  ---
  ```

- **One topic per doc.** No duplication — link to the canonical doc instead of repeating facts.
- **No filler.** Skip "in this document we will..." — start with the content.
- **Tables and lists over prose.** Diagrams in Mermaid (` ```mermaid ` blocks).
- **TODOs** prefixed `> **TODO**:` so `grep -r "TODO" docs/` finds them all.

## Before commit / push

- `grep -rE "TODO|FIXME|TBD" docs/ AGENTS.md DOCS_INDEX.md` — resolve or note open items in the commit message.
- Confirm `DOCS_INDEX.md` matches reality: every doc listed once, deleted docs removed.
- Commit message names the docs touched (e.g., `docs: update kamino-yield design + index`).

## Don't

- Don't create READMEs in subdirectories unless tooling requires them.
- Don't add decorative banners, ASCII art, or "generated by..." tags.
- Don't leave stale `last_updated` values after editing.
- Don't keep dead entries in `DOCS_INDEX.md`.
