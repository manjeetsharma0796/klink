# Services

A directory of HTTP services that klink agents can pay using on-chain USDC, organized by protocol.

* [**MPP services on Solana**](mpp.md) - services that speak the [paymentauth.org MPP](https://paymentauth.org/draft-httpauth-payment-00.html) dialect on Solana, payable via `POST /v1/spend/mpp`.

Want to add a service? Each protocol page has a "How to list yours" section.
